Open-Source Repos for the 15 Agent Builds

GitHub repositories that cover each of the 15 agent engineering builds, with a note on what each one gives you.

The agent ecosystem moves fast, so check that each repo is still actively maintained before committing to it. Items 11, 14 and 15 have no dedicated repo, and item 7 has to be composed from several.

  1. 1

    Durable State Machine Workflow

    • temporalio/temporal and temporalio/sdk-pythonThe standard for durable execution, with retries, signals and crash recovery.
    • langchain-ai/langgraphGraph-based agents with checkpointers for persistence.
    • dbos-inc/dbos-transact-pyLighter-weight durable execution.
    • restatedev/restateLighter-weight durable execution.
  2. 2

    Raw MCP Server & Client

    • modelcontextprotocol/modelcontextprotocolThe spec itself, which is what you need to build without an SDK.
    • modelcontextprotocol/serversReference servers, including database ones, to study.
    • modelcontextprotocol/python-sdkRead the SDK for reference.
    • modelcontextprotocol/inspectorUse the Inspector to test your raw implementation.
    • crystaldba/postgres-mcpA Postgres MCP server with access modes.
  3. 3

    Computer-Use GUI Agent

    • microsoft/playwrightThe browser automation base.
    • browser-use/browser-useLLM-driven browser agent.
    • browserbase/stagehandLLM-driven browser agent.
    • Skyvern-AI/skyvernVision plus DOM for workflow automation.
    • microsoft/OmniParserScreenshot-to-UI-element parsing.
    • anthropics/anthropic-quickstartsIncludes the computer-use demo.
    • trycua/cuaDesktop-level computer use.
  4. 4

    3-Tier Memory & Eviction Engine

    • letta-ai/lettaFormerly MemGPT. Tiered memory, the closest match to your spec.
    • mem0ai/mem0A memory layer with extraction and updates.
    • getzep/graphitiTemporal knowledge graph memory.
    • langchain-ai/langmemMemory framework for LangGraph agents.
    • topoteretes/cogneeMemory framework built on graphs and vectors.

    • crewAIInc/crewAIMulti-agent framework.
    • microsoft/autogenMulti-agent framework.
