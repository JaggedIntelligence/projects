15 Agent Engineering Builds

A portfolio checklist of production-grade projects for engineers building enterprise AI agent systems. Each entry says what to build and why it matters.

  1. 1

    Durable State Machine Workflow

    Build

    A Temporal or LangGraph DAG with checkpoints, exponential retries and crash recovery for a 4-hour data migration task.

    Why

    while True chat loops die on server restarts. Real-world workflows require deterministic state management.

  2. 2

    Raw MCP Server & Client

    Build

    A JSON-RPC Model Context Protocol server exposing a local Postgres DB with scoped read/write permissions, written without a wrapper SDK.

    Why

    Agents need standardized, secure hands. Bespoke API wrappers do not scale across an enterprise.

  3. 3

    Computer-Use GUI Agent

    Build

    A vision-based agent using Playwright and DOM parsing that logs into a legacy web portal, navigates menus via screenshots and downloads a CSV.

    Why

    80% of enterprise software has no API. GUI agents unlock the legacy world text-based agents cannot touch.

  4. 4

    3-Tier Memory & Eviction Engine

    Build

    A memory system with working scratchpads, episodic session compression and semantic vector search with automated TTL eviction.

    Why

    Infinite context causes OOM errors and hallucinations. Memory must be actively managed, scored and pruned.

  5. 5

    Multi-Agent Swarm with Typed A2A

    Build

    A 3-agent swarm (Researcher, Coder, Reviewer) that passes strictly typed Pydantic state objects, never raw text.

    Why

    Single agents fail on complex tasks. Swarms divide and conquer but raw text handoffs cause context drift.

  6. 6

    Sandboxed Code Executor

    Build

    A code-interpreter agent that writes and executes Python in an isolated E2B or gVisor microVM with zero internet egress.

    Why

    Letting an LLM run os.system() on your host machine is a catastrophic security risk.

  7. 7

    Inter-Agent Sanitization Proxy

    Build

    Middleware that intercepts messages between agents, stripping malicious instructions to prevent cross-agent prompt injection.

    Why

    Multi-agent systems create internal attack surfaces. Agent A can be tricked into hijacking Agent B’s tools.

  8. 8

    Async HITL Approval Gate

    Build

    A workflow that drafts a $10k invoice, serializes its state and waits 3 days for a human to click “Approve” in Slack before resuming.

    Why

    High-stakes automation requires human accountability. Agents must know how to pause, wait, and resume cleanly.

  9. 9

    Self-Healing Coder Loop

    Build

    An agent that reads its own stack traces, parses the compiler error, rewrites the failing code, and retries up to 3 times.

    Why

    Agents that fail on the first try are useless. Agents that debug themselves are digital employees.

  10. 10

    Trajectory CI/CD Gate

    Build

    A GitHub Action that replays 100 agent trajectories and blocks the PR if the tool-call sequence deviates from the golden DAG.

    Why

    Grading the final text output hides the fact that the agent hallucinated an API call to get there.

  11. 11

    API-to-Browser Fallback Router

    Build

    A routing layer where if the primary REST API 404s or times out, the agent seamlessly spawns a headless browser to finish the job.

    Why

    The real world is messy. Agents must adapt to broken environments without crashing the workflow.

  12. 12

    Agentic Circuit Breaker

    Build

    A middleware tracking loop depth and tool-call recursion that instantly halts the agent if it enters an infinite spiral.

    Why

    A runaway agent loop is an outage with an invoice. It will burn $500 in API credits before you notice.

  13. 13

    Dynamic Context Budget Orchestrator

    Build

    A pre-flight assembler that strictly allocates tokens across system prompts, retrieved docs and tool schemas per request.

    Why

    Context overflow is the #1 silent killer of production agents.

  14. 14

    Shadow Trajectory Comparator

    Build

    A silent 5% traffic mirror that runs a new agent topology in the background, diffing tool-call paths and costs without affecting users.

    Why

    You cannot A/B test non-determinism safely in production without shadow mode.

  15. 15

    Public Architecture Teardown

    Build

    3 published deep-dives detailing your swarm topology, state-machine design, inter-agent security and cost-per-task analysis.

    Why

    Top AI labs hire Agent Engineers based on their system design judgment not their ability to import LangChain.
